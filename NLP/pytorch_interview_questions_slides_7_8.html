Слайд 7

1Сколько обучаемых параметров в линейном слое?
Для nn.Linear(in_features, out_features) матрица весов имеет размер (out_features, in_features), а bias — (out_features,). Поэтому при bias=True:
N = in_features × out_features + out_features
Например, для Linear(5, 3): 5×3 + 3 = 18.
2Почему на практике редко используют аналитическое решение (формулу нормальных уравнений) для задачи линейной регрессии?
Для МНК можно записать:
w = (XTX)−1XTy
Но при большом числе признаков это дорого: нужно построить и хранить XᵀX, а решение системы размера d×d дорого по времени и памяти. Кроме того, XᵀX может быть плохо обусловлена или вырождена. На практике для классического МНК чаще используют QR/SVD, а на больших данных — градиентные методы и mini-batch обучение.
3Как реализовать логистическую регрессию в PyTorch?
Бинарная логистическая регрессия — это один линейный слой, который выдаёт логит:
import torch
import torch.nn as nn

class LogisticRegression(nn.Module):
    def __init__(self, n_features):
        super().__init__()
        self.linear = nn.Linear(n_features, 1)

    def forward(self, x):
        return self.linear(x)

model = LogisticRegression(n_features=10)
criterion = nn.BCEWithLogitsLoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)
Обучение:
optimizer.zero_grad()
logits = model(x)
loss = criterion(logits.squeeze(), y.float())
loss.backward()
optimizer.step()
Вероятности: torch.sigmoid(logits). Если используем BCEWithLogitsLoss, отдельный sigmoid перед loss не нужен.
4Какие методы можно использовать для подбора весов в линейной модели и как они работают?
  • Аналитическое решение / МНК — сразу находим коэффициенты через решение системы.
  • Gradient Descent — двигаем веса против градиента loss.
  • SGD — оцениваем градиент по одному объекту.
  • Mini-batch GD — по небольшой пачке объектов.
  • Momentum / Adam / RMSProp — меняют способ обновления весов.
  • Newton / L-BFGS / IRLS — методы второго порядка и квазиньютоновские методы.
wt+1 = wt − η ∇L(wt)
5Чем градиентный спуск лучше МНК?
Он не «всегда лучше». Для маленькой линейной регрессии прямое решение может быть отличным. Преимущества GD проявляются на больших данных и в моделях без аналитического решения: можно учиться mini-batch'ами, не хранить огромные матрицы, работать потоково и оптимизировать сложные нелинейные модели.
6Сколько обучаемых параметров у Linear(512, 10)?
Весов: 512 × 10 = 5120. Bias: 10. Итого: 5130 параметров.
8Что такое PyTorch Dataset, DataLoader, какую роль они играют, как написать свой Dataset?
Dataset определяет, сколько у нас объектов и как получить объект по индексу. Обычно реализуются __len__() и __getitem__().
from torch.utils.data import Dataset, DataLoader

class MyDataset(Dataset):
    def __init__(self, X, y):
        self.X = X
        self.y = y

    def __len__(self):
        return len(self.X)

    def __getitem__(self, idx):
        return self.X[idx], self.y[idx]
DataLoader организует batching, shuffle и загрузку данных:
loader = DataLoader(dataset, batch_size=32, shuffle=True)

for X_batch, y_batch in loader:
    ...
Dataset = что читать, DataLoader = как подавать модели.
9Зачем в нейросетях используются функции активации?
Чтобы добавить нелинейность. Несколько линейных слоёв подряд без активаций всё равно эквивалентны одному линейному преобразованию:
W₂(W₁x) = (W₂W₁)x
Без нелинейных активаций глубокая сеть не сможет моделировать сложные нелинейные зависимости.
10Формулы сигмоиды и softmax, их различия и применение
Sigmoid:
σ(x) = 1 / (1 + e−x)
Выход каждого логита независимо лежит в (0,1). Используется в бинарной классификации и multilabel.

Softmax:
pᵢ = ezᵢ / Σⱼ ezⱼ
Вероятности конкурируют и суммируются в 1. Используется в multiclass-классификации с взаимоисключающими классами. Главное: sigmoid — независимые вероятности; softmax — одно распределение по классам.

Слайд 8

11Что такое метод .eval() в PyTorch?
model.eval() переводит модель в evaluation mode. Dropout перестаёт занулять активации, BatchNorm использует накопленные running statistics. Важно: eval() не отключает градиенты. Обычно:
model.eval()
with torch.no_grad():
    pred = model(x)
12Логистическая регрессия считается линейной моделью или нет? Объясни почему.
Да. Вероятность нелинейно зависит от логита:
p(y=1|x) = σ(wTx + b)
Но решающая граница при пороге 0.5 задаётся уравнением:
wTx + b = 0
Это гиперплоскость, то есть линейная decision boundary.
13Зачем нужен BatchNorm2d?
Он нормализует активации в сверточных сетях для тензоров формата (N, C, H, W). Для каждого канала считаются статистики по batch и пространственным координатам:
x̂ = (x − μ) / √(σ² + ε),   y = γx̂ + β
Это часто делает обучение стабильнее и облегчает распространение градиентов.
14Почему BatchNorm почти не используется в NLP задачах?
BatchNorm зависит от статистик batch. В NLP длины последовательностей различаются, batch может быть маленьким, а его состав — сильно меняться. Кроме того, не хочется, чтобы нормализация одного текста зависела от других текстов в batch. Поэтому в Transformers обычно используют LayerNorm.
15Что такое Focal Loss?
Это модификация cross-entropy, уменьшающая вклад легко классифицируемых объектов:
FL = −α(1 − pt)γ log(pt)
Особенно полезна при сильном дисбалансе классов и большом числе «простых» примеров.
16Почему в функции кросс-энтропии используется логарифм?
Он сильно штрафует уверенные ошибки: −log(0.9) ≈ 0.105, а −log(0.001) ≈ 6.91. Кроме того, cross-entropy связана с maximum likelihood: логарифм превращает произведение вероятностей в сумму логарифмов, что удобно для оптимизации и численно устойчивее.
17A размера (2n × 3n) умножаем на B размера (3n × 4n). Сколько поэлементных умножений?
Результат имеет 2n × 4n = 8n² элементов. Для каждого нужно 3n умножений. Итого:
8n² × 3n = 24n³

f'(x) = 2e2xsin(x) + e2xcos(x)
Или:
f'(x) = e2x(2sin(x) + cos(x))
19Классификатор на cross-entropy не делает очень уверенные предсказания 0.0 и 1.0. Почему?
Чтобы sigmoid/softmax дали математически ровно 0 или 1, нужны логиты, стремящиеся к ±∞. При конечных весах вероятности обычно лишь приближаются к границам. На практике также влияют шум, пересечение классов, regularization, weight decay, early stopping и ограниченная ёмкость модели.

15Формула шага SGD; что делают loss.backward(), optimizer.step(), optimizer.zero_grad()?
θt+1 = θt − η∇θL
  • loss.backward() — вычисляет градиенты и записывает их в .grad.
  • optimizer.step() — обновляет параметры.
  • optimizer.zero_grad() — обнуляет старые градиенты, потому что PyTorch по умолчанию их накапливает.
16Что делает model.train(), model.eval(), with torch.no_grad()?
  • model.train() — training mode для Dropout/BatchNorm.
  • model.eval() — evaluation mode для этих слоёв.
  • with torch.no_grad() — отключает построение графа и вычисление градиентов внутри блока.
Типичная validation-секция:
model.eval()
with torch.no_grad():
    for x, y in val_loader:
        logits = model(x)
17Чем отличается работа Dropout на трейне и на инференсе?
На train Dropout случайно зануляет часть активаций с вероятностью p и масштабирует оставшиеся. На inference после model.eval() Dropout ничего не зануляет.
18Зачем в Dropout применяется масштабирование активаций на этапе обучения?
Чтобы сохранить математическое ожидание активации. Если просто занулять элементы с вероятностью p, средний уровень активаций уменьшится. Поэтому оставшиеся значения масштабируют на:
1 / (1 − p)
Это называется inverted dropout.
19Что такое LayerNorm?
LayerNorm нормализует признаки внутри одного объекта:
μ = mean(x),   σ² = var(x)
x̂ = (x − μ) / √(σ² + ε),   y = γx̂ + β
В отличие от BatchNorm, она не зависит от других объектов в batch, поэтому хорошо подходит для NLP и Transformers.

21100 идентичных текстов: у 99 метка 0, у одного метка 1. Что произойдёт с обучением?
Поскольку входы одинаковые, модель не может отличить объект с меткой 1 от остальных. При обычной cross-entropy оптимальное предсказание примерно отражает частоты классов:
P(y=0|x) ≈ 0.99,   P(y=1|x) ≈ 0.01
При argmax модель предскажет 0 для всех 100 объектов и получит accuracy ≈ 99%, но recall по классу 1 будет 0. Это хороший пример того, почему accuracy опасна при сильном дисбалансе.
