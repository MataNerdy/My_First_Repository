#1Основы

Обучение с учителем vs обучение без учителя

Эталонный ответ

Supervised learning — у нас есть признаки X и известные правильные ответы y. Модель учится приближать зависимость f(X) ≈ y.

Примеры supervised-задач:

  • классификация: спам / не спам;
  • регрессия: предсказать стоимость квартиры;
  • прогноз вероятности события / ранжирование: вероятность клика, покупки, дефолта.

Unsupervised learning — есть только X, а целевой переменной y нет. Алгоритм ищет структуру внутри самих данных.

Примеры unsupervised-задач:

  • кластеризация клиентов;
  • снижение размерности — PCA, t-SNE;
  • обнаружение аномалий / скрытых групп.

🎯 Что должен услышать проверяющий

Главное различие — наличие целевой переменной y. В supervised мы предсказываем известную цель, в unsupervised ищем структуру в X.

🧠 Допвопрос

Можно ли использовать кластеризацию, если у нас есть метки классов?

Ответ: Да. Метки можно не использовать при обучении, а затем применять только для внешней оценки качества кластеризации — например, ARI или AMI.
Оценка: не оценено

🎯 Что должен услышать проверяющий

Три пары «компания → продукт/задача» и объяснение, где находится target: клик, будущий спрос, дефолт.

Ответ: Потому что для прошлых моментов времени известен фактически реализованный будущий спрос. Его можно использовать как y.

#4PCA

Зачем понижать размерность данных?

Эталонный ответ

Снижение размерности переводит данные из пространства с большим числом признаков в пространство меньшей размерности, стараясь сохранить полезную структуру.

  • ускоряет обучение и инференс;
  • уменьшает расход памяти;
  • помогает бороться с проклятием размерности;
  • убирает часть избыточных и коррелирующих признаков;
  • может подавлять шум;
  • позволяет визуализировать данные в 2D/3D.

🎯 Что должен услышать проверяющий

Не просто «чтобы было меньше признаков», а ради вычислительной эффективности, борьбы с избыточностью/шумом и визуализации.

🧠 Допвопрос

Всегда ли снижение размерности улучшает качество модели?

Ответ: Нет. Можно потерять полезную информацию. Это компромисс между компактностью представления и информационными потерями.
Оценка: не оценено
#5PCA

Что значит максимизировать дисперсию в PCA?

Эталонный ответ

PCA ищет такое единичное направление w, чтобы дисперсия проекций данных на него была максимальна:

z = Xw,    Var(Xw) → max,    ||w|| = 1

Интуитивно: если спроецировать вытянутое облако точек вдоль его «длинной оси», объекты останутся хорошо различимы. Если спроецировать поперёк — точки могут почти наложиться друг на друга.

Первая компонента сохраняет максимум дисперсии, вторая — максимум из оставшегося при условии ортогональности первой, и так далее.

Ловушка: большая дисперсия не обязана быть самой полезной для конкретного target — PCA вообще не использует y.

🎯 Что должен услышать проверяющий

Максимальная дисперсия = максимально сохранить различия между объектами после линейной проекции. PCA не знает про y.

🧠 Допвопрос

Почему PCA может навредить supervised-модели?

Ответ: Признак с небольшой дисперсией может быть очень важен для y. PCA способен отбросить его, потому что оптимизирует дисперсию X, а не предсказательную силу.
Оценка: не оценено
#6PCA

PCA — линейное преобразование или нет?

Эталонный ответ

Да, линейное. Новые признаки — линейные комбинации исходных:

PC₁ = w₁₁x₁ + w₁₂x₂ + ... + w₁ₙxₙ

В матричном виде после центрирования:

Z = XW

Столбцы W — выбранные направления главных компонент.

🎯 Что должен услышать проверяющий

Да. После центрирования PCA — умножение на матрицу направлений главных компонент.

🧠 Допвопрос

Центрирование само по себе линейное преобразование?

Ответ: Строго математически вычитание среднего — аффинное преобразование. Но сама смена базиса PCA задаётся линейным оператором.
Оценка: не оценено
#7PCA

Как PCA использует матрицу ковариации?

Эталонный ответ

Для центрированной матрицы данных X ∈ Rⁿˣᵈ можно построить:

C = 1/(n−1) · XᵀX

C имеет размер d × d. Затем решается задача:

Cv = λv
  • v — собственный вектор, то есть направление главной компоненты;
  • λ — дисперсия данных вдоль этого направления.

Собственные значения сортируют по убыванию и выбирают первые k собственных векторов.

На практике PCA часто считают через SVD, не формируя covariance matrix явно.

🎯 Что должен услышать проверяющий

Covariance matrix → eigenvectors дают направления компонент, eigenvalues отражают объяснённую дисперсию.

🧠 Допвопрос

Какого размера covariance matrix, если 1000 объектов и 20 признаков?

Ответ: 20 × 20, потому что ковариации считаются между признаками.
Оценка: не оценено
#8Статистика

Что такое ковариация?

Эталонный ответ

Ковариация показывает, как две величины изменяются совместно:

Cov(X,Y) = E[(X−E[X])(Y−E[Y])]

Выборочная версия:

Cov(X,Y) = 1/(n−1) · Σ(xᵢ−x̄)(yᵢ−ȳ)
  • Cov > 0 — обычно растут вместе;
  • Cov < 0 — одна растёт, другая обычно уменьшается;
  • Cov ≈ 0 — выраженной линейной совместной связи нет.

🎯 Что должен услышать проверяющий

Знак ковариации показывает направление линейной совместной изменчивости; величина зависит от масштаба признаков.

🧠 Допвопрос

Ковариация 100 больше и значит сильнее, чем ковариация 10?

Ответ: Не обязательно. Ковариация зависит от единиц измерения и масштаба. Для сравнения силы линейной связи удобнее корреляция.
Оценка: не оценено
#9Статистика

Что такое корреляция?

Эталонный ответ

Корреляция Пирсона — нормированная ковариация:

ρ(X,Y) = Cov(X,Y) / (σₓσᵧ)

Поэтому −1 ≤ ρ ≤ 1.

  • ρ ≈ 1 — сильная прямая линейная связь;
  • ρ ≈ 0 — слабая или отсутствующая линейная связь;
  • ρ ≈ −1 — сильная обратная линейная связь.
Важно: нулевая корреляция не означает отсутствие любой зависимости — зависимость может быть нелинейной.

🎯 Что должен услышать проверяющий

Корреляция — безразмерная нормированная ковариация в диапазоне [−1, 1]. Она характеризует линейную связь.

🧠 Допвопрос

Корреляция означает причинность?

Ответ: Нет. Корреляция показывает статистическую связь, но не доказывает причинно-следственную зависимость.
Оценка: не оценено
#10Линейная алгебра

Собственные числа и собственные векторы матрицы

Эталонный ответ

Собственный вектор v ≠ 0 матрицы A удовлетворяет:

Av = λv

После действия матрицы направление вектора сохраняется; меняется его масштаб и, при отрицательном λ, ориентация.

Из уравнения:

(A − λI)v = 0

Ненулевое решение существует, когда:

det(A − λI) = 0

Сначала находят собственные значения λ, затем для каждого решают систему (A−λI)v=0.

Для больших матриц характеристический полином обычно явно не считают: применяют численные алгоритмы, например QR-итерации и другие итерационные методы.

🎯 Что должен услышать проверяющий

Av = λv: собственный вектор не меняет направление под действием A; λ показывает масштабирование.

🧠 Допвопрос

Почему у covariance matrix в PCA удобно работать с собственными векторами?

Ответ: Матрица ковариации симметрична, поэтому у неё вещественные собственные значения и можно выбрать ортонормированный базис собственных векторов.
Оценка: не оценено
#11t-SNE

Как t-SNE сохраняет локальную структуру?

Эталонный ответ

В высокоразмерном пространстве t-SNE превращает расстояния между точками в вероятности сходства pᵢⱼ: близкие точки получают большую вероятность быть соседями.

В низкоразмерном пространстве строятся аналогичные сходства qᵢⱼ. Затем алгоритм минимизирует расхождение между ними:

KL(P || Q)

Цель — чтобы локальные соседства из исходного пространства по возможности сохранились в 2D/3D.

Главное ограничение: t-SNE не обязан сохранять глобальную геометрию — расстояния между далёкими кластерами, их размеры и взаимное расположение могут искажаться.

🎯 Что должен услышать проверяющий

Высокомерные расстояния → вероятности соседства → низкоразмерные вероятности → минимизация KL divergence. t-SNE прежде всего сохраняет локальное соседство.

🧠 Допвопрос

Почему в t-SNE в низком пространстве используют тяжёлохвостое распределение?

Ответ: Student t-distribution помогает уменьшить crowding problem: далёкие точки могут раздвигаться сильнее, чем при гауссовом распределении.
Оценка: не оценено
#12t-SNE

Что делает perplexity и как её выбирать?

Эталонный ответ

Упрощённо perplexity задаёт эффективный масштаб локального соседства — примерно сколько соседей вокруг точки существенно учитывать.

  • маленькая perplexity → очень локальный взгляд, больше внимания мелким структурам;
  • большая perplexity → учитывается более широкое окружение.

Часто пробуют несколько значений, например 5, 10, 30, 50, и проверяют устойчивость структуры.

Не стоит выбирать perplexity только потому, что картинка «красивее». Если кластеры исчезают при небольшом изменении параметра или random seed — выводы ненадёжны.

🎯 Что должен услышать проверяющий

Perplexity управляет масштабом соседства. Её не подбирают как обычную supervised-метрику; важно проверять несколько значений и устойчивость результата.

🧠 Допвопрос

Можно ли поставить perplexity больше числа объектов?

Ответ: Нет. В практических реализациях perplexity должна быть меньше количества объектов.
Оценка: не оценено
#13t-SNE

Как в t-SNE используется градиентный спуск?

Эталонный ответ

После задания сходств P в исходном пространстве t-SNE оптимизирует координаты точек yᵢ в 2D/3D.

L = KL(P || Q)

На каждой итерации вычисляется градиент:

∂L / ∂yᵢ

и координаты обновляются:

yᵢ ← yᵢ − η · ∂L/∂yᵢ

То есть обучаемыми параметрами являются сами координаты точек на карте.

Функция потерь невыпуклая, поэтому разные инициализации могут давать разные визуализации.

🎯 Что должен услышать проверяющий

Градиентный спуск оптимизирует не веса модели, а низкоразмерные координаты точек, минимизируя KL divergence.

🧠 Допвопрос

Почему одинаковые данные могут дать разные t-SNE-картинки?

Ответ: Из-за невыпуклой функции потерь, случайной инициализации и чувствительности к параметрам.
Оценка: не оценено
#14t-SNE

Как t-SNE сохраняет расположение кластеров?

Эталонный ответ

Правильный ответ: глобальное расположение кластеров t-SNE не сохраняет гарантированно.

Он старается сохранить прежде всего:

  • кто кому локально сосед.

Но нельзя надёжно интерпретировать:

  • точные расстояния между кластерами;
  • относительные размеры кластеров;
  • углы и ориентацию;
  • глобальную форму пространства.

Если красный кластер визуально в два раза дальше от зелёного, чем синий, это не обязано иметь смысл в исходном пространстве.

🎯 Что должен услышать проверяющий

Сказать «никак, если речь о глобальном расположении». t-SNE оптимизирует локальные соседства, а не глобальные расстояния.

🧠 Допвопрос

Можно ли по t-SNE доказать существование кластеров?

Ответ: Нет. t-SNE — в первую очередь средство визуализации. Наличие «островов» нужно подтверждать исходными данными и количественными методами.
Оценка: не оценено

#16Иерархическая

Метрики расстояния и linkage в иерархической кластеризации

Эталонный ответ

Distance metric определяет расстояние между отдельными объектами:

  • Euclidean: √Σ(xᵢ−yᵢ)²;
  • Manhattan: Σ|xᵢ−yᵢ|;
  • cosine distance, Minkowski и другие.

Linkage определяет расстояние между уже образованными кластерами:

  • single — минимальное попарное расстояние; умеет вытянутые формы, но склонен к chaining;
  • complete — максимальное попарное расстояние; тяготеет к компактным кластерам;
  • average — среднее попарное расстояние; компромисс;
  • Ward — выбирает слияние, минимально увеличивающее внутрикластерную дисперсию.

🎯 Что должен услышать проверяющий

Разделить metric и linkage. Metric — между точками, linkage — правило расстояния/слияния кластеров.

🧠 Допвопрос

Почему Ward нельзя бездумно сочетать с любой метрикой?

Ответ: Критерий Ward основан на росте суммы квадратов отклонений и естественно связан с евклидовой геометрией.
Оценка: не оценено
#17K-means

Как начальные центроиды влияют на K-means?

Эталонный ответ

K-means минимизирует внутрикластерную сумму квадратов:

Σₖ Σₓᵢ∈Cₖ ||xᵢ − μₖ||²

Оптимизация может застрять в локальном минимуме, поэтому разные стартовые центроиды дают разные конечные решения.

K-means++ выбирает начальные центры более разумно: следующие центры предпочитаются дальше от уже выбранных.

Кроме того, алгоритм запускают несколько раз с разными инициализациями и оставляют вариант с минимальной inertia.

🎯 Что должен услышать проверяющий

Инициализация влияет, потому что задача невыпуклая. Основные способы улучшения: K-means++ и несколько запусков n_init.

🧠 Допвопрос

Гарантирует ли K-means++ глобальный минимум?

Ответ: Нет. Он только улучшает старт и обычно снижает вероятность плохого локального решения.
Оценка: не оценено
#18Метрики

Какие метрики есть в задаче кластеризации?

Эталонный ответ

Если истинных labels нет — внутренние метрики:

  • Silhouette Score: от −1 до 1, больше — лучше;
  • Davies–Bouldin: меньше — лучше;
  • Calinski–Harabasz: больше — лучше;
  • Inertia / WCSS: для K-means, меньше — компактнее, но она почти всегда уменьшается при росте K.

Если известны истинные классы — внешние метрики:

  • ARI — Adjusted Rand Index;
  • AMI / NMI;
  • homogeneity, completeness, V-measure.

🎯 Что должен услышать проверяющий

Разделить внутренние метрики без y_true и внешние метрики, когда эталонные labels известны.

🧠 Допвопрос

Почему нельзя просто выбрать K по минимальной inertia?

Ответ: Потому что inertia монотонно уменьшается при увеличении числа кластеров и достигнет нуля, если каждый объект станет отдельным кластером.
Оценка: не оценено
#19K-means

Как адаптировать K-means к категориальным признакам?

Эталонный ответ

Классический K-means плохо подходит категориям, потому что использует среднее значение как центроид и обычно евклидово расстояние.

Для категорий «Москва», «Казань», «Тбилиси» среднее значение не имеет смысла.

Варианты:

  • One-Hot Encoding + K-means — возможно, но геометрия расстояний не всегда содержательна;
  • K-modes — для категориальных данных, вместо среднего использует моду;
  • K-prototypes — для смешанных числовых и категориальных данных.

🎯 Что должен услышать проверяющий

Объяснить проблему центроида-среднего и назвать One-Hot, K-modes, K-prototypes.

🧠 Допвопрос

Почему label encoding категорий + K-means опасен?

Ответ: Числа 0,1,2 создают искусственный порядок и расстояния между категориями, которых в реальности может не быть.
Оценка: не оценено
#20DBSCAN

Как eps и min_samples влияют на DBSCAN?

Эталонный ответ

eps — радиус локальной окрестности.

  • слишком маленький eps → много noise и мелких кластеров;
  • слишком большой eps → разные группы сливаются.

min_samples — сколько точек должно быть в eps-окрестности, чтобы точка считалась core point.

  • большой min_samples → требуем более высокой плотности;
  • маленький → кластер образуется легче.

Выбор eps: часто используют k-distance plot и ищут «колено» графика расстояния до k-го соседа.

Неравномерная плотность: один eps плохо подходит плотным и разреженным кластерам одновременно. Часто лучше OPTICS или HDBSCAN.

🎯 Что должен услышать проверяющий

eps управляет радиусом, min_samples — требуемой локальной плотностью. Для разной плотности классический DBSCAN проблемен.

🧠 Допвопрос

Почему перед DBSCAN особенно важно масштабирование признаков?

Ответ: Потому что DBSCAN основан на расстояниях. Признак с большим численным масштабом может полностью доминировать в метрике.
Оценка: не оценено
#21DBSCAN

DBSCAN для обнаружения аномалий

Эталонный ответ

DBSCAN делит точки на:

  • core — достаточно плотная окрестность;
  • border — сама не core, но соседствует с core;
  • noise — не попала ни в один плотный кластер.

В популярных реализациях noise получает метку -1, поэтому такие точки можно использовать как кандидатов в аномалии.

Плюсы:

  • не требует заранее размеченных аномалий;
  • умеет находить кластеры сложной формы;
  • одновременно кластеризует и выделяет шум.

Минусы: редкий, но нормальный кластер тоже может стать noise; результат чувствителен к eps, min_samples, масштабу и метрике.

🎯 Что должен услышать проверяющий

Noise ≠ автоматически «истинная аномалия», а только объект вне найденных плотных областей. Это кандидат на аномалию.

🧠 Допвопрос

В чём преимущество DBSCAN перед K-means для аномалий?

Ответ: K-means принудительно относит каждый объект к одному из K кластеров. DBSCAN умеет явно оставить точки вне кластеров как noise.
Оценка: не оценено
